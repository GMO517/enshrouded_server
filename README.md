# 霧鎖王國開服工具

Windows 上的霧鎖王國(Enshrouded)專用伺服器管理工具,一鍵開服、關服,可以改設定、管身分組與黑名單、備份地圖。

## 下載

到 [Releases 頁面](https://github.com/GMO517/enshrouded_server/releases/latest),在最新版本下方的 Assets 找到 `EnshroudedServerTool.exe`,點它下載,下載後雙擊就能用,不需要安裝。(找不到的話,點頁面右側欄的 Releases。)

## 使用

1. 到 Valve 下載 [SteamCMD](https://steamcdn-a.akamaihd.net/client/installer/steamcmd.zip),解壓縮到任意資料夾。
2. 打開工具,進「伺服器安裝」,選好 SteamCMD 資料夾和遊戲伺服器要放的資料夾,按「安裝伺服器」。
3. 裝好後到「控制台」按「一鍵開服」。

之後要更新伺服器,關服後在「伺服器安裝」按「更新伺服器」。

## 功能

- **控制台**:開服、關服、在線成員、記錄。關服會正常存檔。也會顯示可用的連線位址,並可一鍵放行 Windows 防火牆。
- **伺服器設定**:名稱、人數、難度,滑桿調整,滑鼠移到名稱上有說明。
- **身分組**:設定密碼與權限。密碼不能重複,最多一個不設密碼。
- **黑名單**:查看、解除封鎖、手動新增。
- **地圖備份**:備份、還原、刪除,顯示時間。還原前會先自動備份目前的地圖。

## 注意

- 設定與地圖備份、還原都要先關閉伺服器。
- 每次存設定前會自動備份舊檔,放在伺服器資料夾的 `config-backups`。
- 工具本身不做任何連線處理,只負責啟動伺服器,連線由遊戲伺服器自己處理。

## 連線方式

玩家加入伺服器有兩種方式:

- **Steam 好友**:主持人的遊戲連上伺服器後,好友可從遊戲選單的 Steam 好友清單加入。
- **虛擬網路**(Radmin VPN、Tailscale):所有人加入同一個虛擬網路,再到遊戲的「搜尋 IPv4」輸入虛擬網路位址,例如 `26.x.x.x:15637`。伺服器開著即可,主持人不必在線。

「控制台」的「連線位址」會列出本機、區網與虛擬網路的位址,可直接複製。伺服器主機本身使用 `127.0.0.1:15637` 連線。

注意事項:
- 以位址連線時,主機的防火牆需放行 UDP 15637,可在「控制台」按「放行 UDP」。
- 以公網 IP 直連未經驗證。如需從外網直連,須自行在路由器轉發 UDP 15637。
- 玩家與伺服器的遊戲版本需一致,更新伺服器後請確認。

## 開發

```bash
npm install
npm start        # 開發執行
npm run build    # 打包,輸出 dist\EnshroudedServerTool.exe
```

打包時專案路徑要短,`productName` 要維持英文,否則 NSIS 會失敗。

# 霧鎖王國開服工具

Windows 上的霧鎖王國(Enshrouded)專用伺服器管理工具,一鍵開服、關服,可以改設定、管身分組與黑名單、備份地圖。

## 使用

1. 到 Valve 下載 [SteamCMD](https://steamcdn-a.akamaihd.net/client/installer/steamcmd.zip),解壓縮到任意資料夾。
2. 打開工具,進「伺服器安裝」,選好 SteamCMD 資料夾和遊戲伺服器要放的資料夾,按「安裝伺服器」。
3. 裝好後到「控制台」按「一鍵開服」。

之後要更新伺服器,關服後在「伺服器安裝」按「更新伺服器」。

## 功能

- **控制台**:開服、關服、在線成員、記錄。關服會正常存檔。也會顯示給朋友的連線位址(公網 IP:連接埠),並可一鍵放行 Windows 防火牆。
- **伺服器設定**:名稱、人數、難度,滑桿調整,滑鼠移到名稱上有說明。
- **身分組**:設定密碼與權限。密碼不能重複,最多一個不設密碼。
- **黑名單**:查看、解除封鎖、手動新增。
- **地圖備份**:備份、還原、刪除,顯示時間。還原前會先自動備份目前的地圖。

## 注意

- 設定與地圖備份、還原都要先關閉伺服器。
- 每次存設定前會自動備份舊檔,放在伺服器資料夾的 `config-backups`。
- 工具本身不做任何連線處理,只負責啟動伺服器;連線是遊戲伺服器自己向 Steam 登記後,由玩家直接連到你的公網 IP。

## 讓朋友連進來

1. **防火牆**:到「控制台」按「放行 UDP」(會跳出系統管理員授權),或在第一次開服時對 Windows 的詢問視窗按允許。
2. **路由器**:登入路由器,把 UDP 15637 轉發到伺服器這台電腦的區網 IP。連接埠以設定檔的 `queryPort` 為準,預設是 15637。
3. **給朋友**:朋友在遊戲裡開「顯示專用伺服器」,搜尋伺服器名稱,或輸入「控制台」顯示的位址。

連不上時:
- 路由器的 NAT 較嚴格,或網路是 CGNAT(ISP 不給你獨立公網 IP),轉發會無效。可以改用 [Radmin VPN](https://www.radmin-vpn.com/) 或 Tailscale,大家加入同一個虛擬網路後,朋友連虛擬網路的 IP。
- 確認朋友的遊戲版本和伺服器一致,更新後都要重新確認。

## 開發

```bash
npm install
npm start        # 開發執行
npm run build    # 打包,輸出 dist\EnshroudedServerTool.exe
```

打包時專案路徑要短,`productName` 要維持英文,否則 NSIS 會失敗。
